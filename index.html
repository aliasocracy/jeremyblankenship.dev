Outside work I keep a Proxmox homelab, build sites for local businesses, and maintain Hermes Agent plugins and MCP servers.

Selected projects

Descriptions from each repository’s README or GitHub summary.

  • hermes-tool-slimmer

    Hermes Agent plugin that trims tool schemas sent with each model request—keyword-ranked selection, optional experimental modes, and a dashboard for savings. Fails open to the full tool list when selection errors.

  • CouncilRouter

    Multi-model AI consensus proxy with deliberation rounds, code-aware synthesis, and a Devil’s Advocate module that challenges consensus.

  • hermes-memory-mcp

    Stdio MCP server exposing Hermes Agent persistent memory files and local session search to MCP clients (Hermes, Cursor, Claude, and others).

  • hermes-webhook-router

    Pre-router that filters and transforms webhook payloads before they trigger Hermes Agent runs, so noisy SaaS events do not burn tokens on every delivery.

  • hermes-threshold

    FastAPI service for proactive Hermes wake cycles: deterministic decisions to sleep, reflect, draft, notify, or request approval, with SQLite-backed state.
